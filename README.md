# Eko Dom Projekt – strona internetowa

Nowa strona EkoDomProjekt Sp. z o.o. (Lublin): dotacje Czyste Powietrze, montaż klimatyzacji, deszczówka, pompy ciepła, fotowoltaika, magazyny energii, termomodernizacja, audyt energetyczny, wirtualne biuro, sklep, blog i regulamin programu poleceń.

## Zawartość
- `index.html` – cała strona (HTML, CSS i JS w jednym pliku; podstrony działają przez adresy `#oferta-…`, `#blog`, `#sklep`, `#biuro-kontakt`, `#regulamin-polecen`)
- `img/` – zdjęcia, plakaty, grafiki, realizacje i zdjęcia produktów
- `.htaccess` – kompresja i cache dla serwera Apache (np. LH.pl)

## Publikacja
- **GitHub Pages:** wgraj zawartość do repozytorium i włącz Pages dla gałęzi `main`, folder `/ (root)`.
- **LH.pl:** wgraj zawartość folderu (razem z `.htaccess`) do katalogu domeny, np. `public_html`, przez Menedżer plików albo FTP.

Strona nie wymaga budowania ani bazy danych.
